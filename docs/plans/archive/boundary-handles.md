# 境目につまみを出す（右ペインの幅・STEP 3 のアウトラインの開閉）

## 目的・背景

- 右ペインの幅は左端の境をドラッグで変えられるが、境に何も出ていないので、変えられることが分からない
- STEP 3 のアウトラインのリストは見出しの「閉じる ›」と、閉じたあとの縦書きの帯で開閉していた。これも境のつまみに揃える

（2026-11-11 ユーザーの要望）

## 対応方針

- **右ペインの境**: 境の高さの中央に、小さいつまみ（縦長の丸い板に点 3 つ）をいつも出す。乗せる・ドラッグ中・フォーカスで深緑に。動き（ドラッグ・ダブルクリック・← →）は変えない
- **STEP 3 のアウトライン**: 本文の欄とアウトラインのリストの境（すき間）の中央に、同じ形のつまみ（中は矢印）を出す。押すと閉じる・もう一度押すと開く
  - 開いているとき「›」（右に閉じる）、閉じているとき「‹」（開く）
  - 閉じると右の列は全部隠れ、本文の欄が右いっぱいまで広がる（つまみだけ右端に残る）。見出しの「閉じる ›」と縦書きの帯はやめる
  - 開閉をブラウザに覚えるのと、閉じている間は右の列の「書き出し →」を出さないのは今までどおり
- 変えるのは `src/browser/views/draft.ts` と `web/style.css`

## テスト方針

DOM と CSS なので node のテストは無い。ブラウザ（Playwright）で見た目と、つまみで開閉できること・右ペインのドラッグが今までどおり動くことを確かめる。
