# 各 STEP の下に次のステップへのボタン

## 目的・背景

ユーザーの要望（2026-11-08）: 各 STEP の画面の下に、次のステップへ進むボタンを付ける。
左のタイルで行き来するだけでなく、画面を上から埋めて、下のボタンで次へ進む、という流れで書けるようにする。

## 対応方針

- 編集画面の中央のペインの一番下に「STEP 2 アイデアへ →」のようなボタンを置く（右寄せ・深緑の主ボタン）
  - STEP 1 → 2 → 3 → 4。STEP 4（下書き）は最後なので出さない（書き出しを作ったら、そこに書き出しを置くか考える）
  - 中身はリンク（`#/p/<id>/<次の段階>`）。押すと左のタイルと同じく、その場で段階が切り替わる（読み直さない・離れる段階は保存する）
- アウトライン・下書きのように中身が高さいっぱいに広がる段階でも、ボタンはその下（中央のペインの下端）に出る
- 段階を移ったら中央のペインのスクロールを先頭に戻す（いまは同じ要素を使い回すので、前の段階のスクロール位置が残る）

### 作りながら直したこと

- 中身が中央のペインより高いとき、中身が縮んでボタンの下に潜り込んでいた → 段階の中身は縮めない（足りなければ中央のペインがスクロール）。
  アウトラインだけは高さを決めて図の中でスクロールさせる（`.stage-body.fill`）
- 下書きの右のアウトラインのリストが長いと中央のペインごと伸びていた → リストは本文の欄と同じ高さにして中でスクロール（`contain: size`）
- 課題・アイデアの中身の幅の上限（760px / 860px）を外し、ボタンと右端を揃えた

## 影響範囲

- `src/browser/views/edit.ts`・`web/style.css`

## テスト方針

- `npm test`・`npm run typecheck`・`npm run lint`
- 3017 番でヘッドレスブラウザ: 課題 → アイデア → アウトライン → 下書きとボタンで進める・下書きにはボタンが無い・
  進むときに前の段階が保存される・スクロールが先頭に戻る
