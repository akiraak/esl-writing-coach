# 表現集の例を増やす

## 目的・背景

学習ガイドの表現集は 5 グループ・26 個で、書いているうちに同じ表現ばかりになる。授業の opinion paragraph で使える定型表現を増やす。

## 対応方針

- `src/shared/guide.ts` の `PHRASES` に足す（今のグループはそのまま、表現を増やす）
  - 意見を述べる・理由を並べる・例を挙げる・結論で締める・つなぎ: それぞれ 2 倍くらいに
  - 新しいグループ「反対の意見にふれる」（役割の色なし）: Some people say that / It is true that … など
- 形は今と同じ（文頭に置くものは大文字で始めてカンマまで、文中で使うものは小文字）。押すとそのまま下書きに入るので、`〜` などは入れない
- 画面（`guide-content.ts`）と CSS は変えない（チップが折り返して並ぶ）

## 影響範囲

`src/shared/guide.ts` だけ。学習ガイド画面と編集画面の引き出しの両方に出る。

## テスト方針

`test/guide.test.ts` の「重複していない」が通ること。`npm test`・`npm run typecheck`・`npm run lint`。
