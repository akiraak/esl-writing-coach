# 表現集から下書きへの挿入

## 目的・背景

「後で足すもの」の 1 つ。下書き（STEP 4）を書いている途中に、右ペインの表現集の表現を押すと、本文のカーソルの位置に入るようにする。
2026-11-08、次の作業として Claude が選んだ（STEP 4 で毎回使える・API を使わない・小さい）。

## 対応方針

- 右ペインの「表現集」の各表現を押せるようにする（学習ガイド画面では押せない。見るだけのまま）
- 下書き（STEP 4）を開いているときは、押すと**本文のカーソルの位置**（選んでいる文字があれば置き換え）に入れる
  - 押したときに本文の欄からフォーカスとカーソルの位置を奪わない（押した瞬間の `mousedown` を止める）
  - 前の文字が空白・改行・本文の先頭でなければ、前に空白を 1 つ足す。後ろには空白を 1 つ足す（続けて打てるように）
  - ブラウザの「元に戻す」（Ctrl+Z）で戻せるように、`execCommand('insertText')` で入れる（使えなければ `setRangeText`）
  - 入れたら語数・文数のメーターと自動保存も、打ったときと同じく動く（`input` を起こす）
- 下書き以外の段階では、押すと「下書き（STEP 4）を開くと本文に入れられます」と知らせる
- 表現集の上に「押すと下書きのカーソルの位置に入ります」と添える（右ペインだけ）
- 入れる先は、下書きの画面が開いている間だけ登録する（`src/browser/phrase-target.ts`。段階を移ったら外す）
- 空白の足し方は純関数にして node で確かめる（`src/shared/insert.ts`）
