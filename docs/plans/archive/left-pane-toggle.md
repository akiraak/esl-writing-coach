# 左ペイン（段階のタイル）を閉じられるようにする

## 目的・背景

編集画面の左ペイン（STEP 1〜3 のタイル。200px）も、STEP 3 のアウトラインと同じつまみで閉じて、中央を広げられるようにする（2026-11-11 ユーザーの要望）。

## 対応方針

- 左ペインと中央の境の中央に、アウトラインの開閉と同じ形のつまみ（`.side-handle`）を置く。開いているとき「‹」（左に閉じる）、閉じているとき「›」（開く）
- 閉じると左ペインは全部隠れ、中央が左いっぱいまで広がる（つまみだけ左端に残る）。どの段階でも効く
- 開閉はブラウザに覚える（`localStorage` の `esl-writing.left-pane`。読めなくても開いた状態で動く）
- 閉じている間の段階の移動は、中央の下の「STEP n へ →」・右の列の「STEP 2 で作る」などのリンク、またはつまみで開いてタイルから
- 右ペインの幅の上限の計算（`maxPaneWidth`）は、左ペインを 200px として数えるまま（閉じていても変えない）
- 変えるのは `src/browser/views/edit.ts` と `web/style.css`

## テスト方針

DOM と CSS なので node のテストは無い。ブラウザ（Playwright）で、閉じると中央が広がること・開き直せること・読み直しても覚えていること・右ペインの境と学習ガイドの引き出しが崩れないことを確かめる。
