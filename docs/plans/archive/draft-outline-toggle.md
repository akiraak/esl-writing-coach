# STEP 3 のアウトラインのリストを右に閉じられるようにする

## 目的・背景

STEP 3 の本文の欄の右にアウトラインのリスト（250px）がいつも出ていて、本文の欄が狭い。
アウトラインを右に閉じて、本文の欄を広げられるようにする（2026-11-11 ユーザーの要望）。

## 対応方針

- アウトラインのリストの見出しに「閉じる ›」。押すと右の列が細い帯（「‹ アウトライン」の縦書きのボタン）になり、本文の欄がその分広がる
- 帯のボタンを押すと元に戻る。開閉はブラウザに覚える（`localStorage` の `esl-writing.draft-outline`。読めなくても開いた状態で動く）
- 閉じている間、右の列の「書き出し →」は出さない（ヘッダの「書き出し」から同じダイアログを開ける）
- 変えるのは `src/browser/views/draft.ts` と `web/style.css`。右ペイン（AI）の幅の変え方はそのまま

## テスト方針

DOM の部分なので node のテストは無い。ブラウザ（Playwright）で、閉じると本文の欄が広がること・開き直せること・読み直しても覚えていることを確かめる。
