# Ctrl+S でブラウザの保存を出さない

## 目的・背景

保存しようとしてつい Ctrl+S を押すと、ブラウザの「ページを保存」のダイアログが出てしまう（2026-11-11 ユーザーの要望）。
アプリは自動保存なので、Ctrl+S では何も出さないようにする。

## 対応方針

- `src/browser/main.ts` で `keydown` の Ctrl+S（Mac は Cmd+S）を `preventDefault()` する。どの画面でも
- ついでに、未保存の分があればその場で保存する（3 秒待たずに。`View.flush()`）。競合で止まっている自動保存は動かさない（`flush` の今の動きのまま）

## 影響範囲

`src/browser/main.ts` だけ。

## テスト方針

DOM の部分なので node のテストは無い。ブラウザ（Playwright）で、Ctrl+S が止まること・すぐ保存されることを確かめる。
