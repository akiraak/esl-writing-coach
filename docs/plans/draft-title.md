# STEP 3 でタイトルを書けるようにする

## 目的・背景

提出するパラグラフにはタイトルを付ける。今はタイトルを書く場所が無く、提出用のファイル（.docx・PDF）は**課題のテーマ**を中央のタイトルとして出している。
テーマは日本語で書くこともある（自分で決める問い・メモなので）ので、そのまま英語の提出物に出ると困る。

2026-11-12 ユーザーの要望:

- STEP 3 でタイトルを書けるようにする。**下書きの本文とは別の項目**にする
- ファイルを作るとき（書き出し）にも反映する
- **テーマはファイルの出力に含めない**

## 対応方針

### 保存（タイトルは下書きとは別に持つ）

- DB の `stages` に、段階と同じ形の行（`stage = 'title'`）として持つ。`rev`・競合の判定・自動保存は段階と同じ仕組み（`StageEditor`）をそのまま使う。表の形は変えない（版は上げない）
- 画面の「段階」（STEP 1〜3 のタイル = `STAGES`）は 3 つのまま。保存できる項目は「段階 + タイトル」として分けて持つ（`src/shared/types.ts` に `DOCS = [...STAGES, 'title']` のような並びを足す）
  - API は今の `GET/PUT /api/paragraphs/:id/stages/:stage` で `title` も受ける
  - 一覧の進み具合（`started`）・タイルの状態の行は 3 つの段階だけで数える（タイトルだけ書いても「下書きに着手」にはしない）。更新日はタイトルの保存も反映する
- 中身は 1 行のテキスト（改行は入れさせない。前後の空白は書き出すときに落とす）。前からあるパラグラフは空

### 画面（STEP 3）

- 本文の欄の上（課題の帯の下）に、1 行の入力欄「タイトル」。英文の見出しなので Georgia・中央寄せ、placeholder は `Title`
- 日本語が混じっていれば、本文と同じ注意を出す（タイトルも英語のみ）
- **語数・文数のメーターにはタイトルを数えない**（課題の語数は本文の指定のため）
- 自動保存は下書きと同じ（3 秒）。ヘッダの保存の状態は 3 つの段階 + タイトルをまとめて出す。競合したときの知らせは STEP 3 の画面に出す
- 左のタイル・一覧のカードにはタイトルを出さない（一覧はテーマのまま）

### 書き出し

- **提出用のファイル（.docx・PDF）**: 中央のタイトルを、テーマではなく**このタイトル**にする。空ならタイトルの行を出さない。**テーマはどこにも出さない**
  - `src/shared/document.ts` の `DocumentInput.theme` を `title` に変える。体裁（中央・Times New Roman 12pt・行間 2 行）はそのまま
- **プレーンテキスト（コピー・.txt）**: タイトルがあれば 1 行目にタイトル、空行を 1 つ、そのあとに本文（`src/shared/export.ts`）。タイトルが空なら今までどおり本文だけ
- 書き出しのダイアログの確かめる欄（プレビュー）にもタイトルを出す。説明の「テーマをタイトルに」を直す
- ファイル名はパラグラフの id のまま

### AI（Phase 3）

- **AI に質問**: タイトルも渡す（タイトルについて聞けるように。実際に「タイトルを訳すと？」と聞いている）
- **採点**: タイトルも渡し、綴りの誤りの一覧と指摘の対象にする（点数の基準は変えない）。「本文が変わっています」の判定にタイトルも入れる
- **日本語訳**: タイトルを最初の 1 行として訳す
- どれも「送るもの」の表示に「タイトル」を足す

## 決めたこと（2026-11-12 ユーザーの決定。おすすめの形のまま）

1. プレーンテキスト（コピー・.txt）にもタイトルを入れる（1 行目 + 空行）
2. 語数・文数にタイトルは数えない
3. AI にタイトルを渡す（AI に質問・採点・日本語訳の 3 つとも）

- `CLAUDE.md`（書く流れ・書き出し・表・API）

## Phase

1. **保存と入力欄**: タイトルの行の読み書き（API・保存層）、STEP 3 の入力欄、自動保存・競合・保存の状態
2. **書き出し**: .docx・PDF のタイトルをこのタイトルに（テーマは出さない）、プレーンテキスト、ダイアログのプレビューと説明
3. **AI に渡す**: AI に質問・採点・日本語訳
4. **後片付け**: `CLAUDE.md`、`DONE.md`、プランを archive へ

## テスト方針

- 保存層・API: タイトルの読み書きと競合（409）、一覧の進み具合に数えない、不正な段階名は今までどおり 400
- `export.ts`: タイトルあり・なし・空白だけ。`document.ts`・`docx.ts`: タイトルが出る・空なら行が無い・**テーマが出力に入らない**
- Phase 3: プロンプトにタイトルが入る・採点の「変わっています」の判定
- 画面はブラウザ（Playwright）で: 入力 → 自動保存 → 読み直しても残る、書き出しのプレビュー、.docx の中身
